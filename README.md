# DSH Life Panels

A set of sidebar plugins for DeepSeek Harness. Each plugin adds a panel to the Web UI and a tool the agent can call.

| Plugin | Panel | Agent tool | What it does |
| --- | --- | --- | --- |
| [calendar-reminders](plugins/calendar-reminders) | 日历 | `calendar_reminders` | Month calendar and reminder list. A reminder can post a chat message in its session when it is due. Reminders can repeat daily, on weekdays, weekly, monthly or yearly; completing one records a done copy and moves it to the next date. |
| [news-feeds](plugins/news-feeds) | 新闻 | `news_feeds` | RSS/Atom reader with tech, business and world categories, search, and "read later". |
| [reading-list](plugins/reading-list) | 稍后读 | `reading_list` | Save links or text; the article text is extracted in the background. Tracks progress, notes and tags. |
| [travel-planner](plugins/travel-planner) | 旅行 | `travel_planner` | Day-by-day itinerary, budget and expenses, packing list, 16-day Open-Meteo forecast. |
| [podcasts](plugins/podcasts) | 播客 | `podcasts` | Apple Podcasts directory search and chart, RSS subscriptions, queue, resume playback. |
| [vocabulary](plugins/vocabulary) | 单词 | `vocabulary` | IELTS and TOEFL word books with spaced repetition (SM-2 style, four grades), daily new-word quota, pronunciation, a personal word list and study history. |
| [focus](plugins/focus) | 专注 | `focus` | Pomodoro timer with white noise synthesized in the browser (rain, ocean, campfire, pink, brown, white). Noise plays during focus and stops on breaks. Daily, weekly and per-task stats. |
| [youtube](plugins/youtube) | YouTube | `youtube` | Follow channels without a Google account: subscribe by link, @handle or channel search, see the latest uploads across channels, mark watched, and play in an embedded player. Uses the same web JSON endpoints youtube.com calls, so a YouTube redesign can break it; publish times are estimated from labels like "3 days ago". |
| [iptv](plugins/iptv) | 电视 | `iptv` | Live TV from M3U/M3U8 playlists: browse by group, search, favorite, and play HLS streams in the panel. Ships with iptv-org playlists (China enabled) and accepts your own. Streams and segments are fetched through the Host so CORS and http:// sources work, optionally via an HTTP, HTTPS or SOCKS5 proxy set in the panel (stored per machine in `iptv-local.json`, never synced); non-HLS sources (RTMP, RTSP, UDP) are not supported. A phone remote (遥控器) can be turned on in the panel: it serves a small page on the LAN (port 8790 by default), paired by scanning a QR code; it relays channel, play/pause, volume and number commands to the TV page and never exposes stream URLs or the proxy. Bundles hls.js (Apache-2.0) and Project Nayuki's QR Code generator (MIT, via qrcode.react). |
| [market](plugins/market) | 市场 | `market` | Global markets: a three.js globe of 18 stock exchanges with live open, lunch and closed state and each exchange's headline index (drag to rotate, click a city; the night side follows the sun), 21 world indices, gold, oil and other commodities, major currency pairs, the top 12 coins, and a watchlist of US and Hong Kong stocks, ETFs and coins with optional positions and profit and loss. No mainland China A-share data, no account or API key. Sources: Eastmoney (indices, commodities, FX), Tencent (US and Hong Kong stocks), CoinLore and Bybit (crypto), all unofficial public endpoints that may lag or change; exchange hours ignore public holidays. Information only, not investment advice. three.js r149 (MIT) is vendored in `plugins/market/vendor`, and the land map is generated by `scripts/gen-land.mjs` from Natural Earth data via `world-atlas`. |
| [notes](plugins/notes) | 笔记 | `notes` | Notes in Markdown: a list beside an autosaving editor with edit, split and preview modes, a formatting bar, list continuation on Enter, tickable `- [ ]` checklists, #tags, search and pinning. Rendering builds React elements, never HTML, so note text cannot inject markup. The agent can save, look up and tick off notes from chat. |
| [personal-assistant](plugins/personal-assistant) | 语音助手 | — | Voice assistant on Telegram, built on LiveKit: call it and talk, or let it call you when a task needs you or has finished; the to-dos from a call become a DSH session on a task board. Needs a LiveKit Cloud project, a spare Telegram user account, Node 20+ and Python 3.10+; see [its README](plugins/personal-assistant/README.md). Formerly [dsh-personal-assistant](https://github.com/elanchou/dsh-personal-assistant). Not exposed over the LAN. |
| [elans-stack](plugins/elans-stack) | ElansStack | — | Groups the panels above into one sidebar entry with a Today overview: one capture box that files a line as a note, a reminder (dates and times such as “明天下午3点” or “next fri” are parsed) or a reading-list link; DSH sessions that need you or are running; weather, due reminders, trip countdown, global markets, headlines, quick note, and the state of cloud sync and the Agent API. The `quick_capture` tool does the same filing from chat or for external agents and three tab groups: Personal (calendar, trips, notes, voice assistant, vocabulary, focus), Feeds (news, market, podcasts, YouTube, reading list, TV) and one Settings tab that holds cloud sync, LAN, the Agent API and the feature switches (which hide any panel or overview card from ElansStack). Optional: with it off, each panel keeps its own sidebar icon. |
| [lan-host](plugins/lan-host) | 局域网 | `lan_host` | Serves the panels above to an iPad or another device on the local network. Scan a QR code to pair (a key in the link becomes a cookie), then the device loads each plugin's own client bundle and talks to the same Host-side operations. Cloud sync and iCafe are never exposed; each other panel can be hidden. Plain HTTP on the LAN, so use it on a network you trust. The TV phone remote and proxy settings stay on the computer. |
| [agent-api](plugins/agent-api) | Agent 接口 | `agent_api`, `dashboard_today` | MCP (Streamable HTTP) and plain HTTP access to the panel tools for agents outside DSH, such as Muse: per-agent tokens stored as hashes, read-only or read-write, a call log, and an optional public https URL through a Cloudflare quick tunnel. `dashboard_today` gives a one-call daily overview. See [docs/agent-access.md](docs/agent-access.md). |
| [cloud-sync](plugins/cloud-sync) | 云同步 | `cloud_sync` | Syncs the data of the plugins above to a private GitHub repository with a per-record three-way merge, in at most one commit per sync. Agents that can only reach GitHub change data by committing JSON-line requests to `dsh-sync/inbox/`; results come back in `dsh-sync/outbox/results.jsonl`. |

The UI is Chinese and English, follows the Harness theme tokens, and works in light and dark mode. Surfaces use frosted glass: translucent layers over a soft ambient backdrop, with backdrop blur reserved for the floating bars and toasts that content scrolls beneath (blurring every list card made scrolling stutter); they fall back to opaque layers when the browser lacks `backdrop-filter` or the system asks for reduced transparency.

## Install

Requires Node.js 20 or newer and a DeepSeek Harness profile.

```sh
git clone git@github.com:elanchou/dsh-life-panels.git
cd dsh-life-panels
npm run build        # generates client.js / common.js / merge.js in each plugin
```

Then install each plugin directory as a bundle. In a Harness chat, ask the agent to install them, or use the plugin manager with the absolute path, for example `…/dsh-life-panels/plugins/podcasts`. Install only the ones you want; cloud-sync works with any subset.

After pulling updates, run `npm run build` again and reinstall (or bump the version) so the Harness reloads the changed files.

## Data

Each plugin stores one JSON file in `$DSH_HOME/plugin-data/` (`calendar-reminders.json`, `news-feeds.json`, `reading-list.json`, `travel-planner.json`, `podcasts.json`, `vocabulary.json`, `focus.json`, `youtube.json`, `iptv.json`, `market.json`, `notes.json`, `elans-stack.json`; `iptv-local.json` and `lan-host-local.json` are per machine and never synced). Writes are atomic. If another writer replaces a file (for example cloud-sync), the plugin re-reads it and merges its own unsaved changes instead of overwriting.

The vocabulary word books in `plugins/vocabulary/books/` are derived from [ECDICT](https://github.com/skywind3000/ECDICT) (MIT): the entries tagged `ielts` (5,040 words) and `toefl` (6,974 words), with phonetics and up to three lines of Chinese meaning. Exam words that are not on the Chinese middle/high-school lists come first, each group ordered by corpus frequency. See `books/ECDICT-LICENSE`.

## Cloud sync

1. Create a [fine-grained token](https://github.com/settings/personal-access-tokens/new) with **Contents: Read and write** on the sync repository. To let the plugin create the repository, the token also needs account **Administration: write**; otherwise create an empty private repository first.
2. Open the 云同步 panel, enter the token and the repository name (default `dsh-life-data`), and connect.
3. Connect the same repository on every computer.

How it works:

- Each data file is stored as `dsh-sync/<plugin>.json`, and every sync is a commit, so GitHub keeps the history.
- The last synced version is kept locally as the merge base. Records (`id`, `key`, or `url` on first sync) are merged one by one: additions and deletions from both sides are kept, an edit wins over a concurrent delete, and when both sides changed the same field the one with the newer `updatedAt` wins.
- Uploads are conditional on the file's blob sha. If another machine pushed first, the plugin pulls, merges and retries.
- Sync runs at startup, every 10 minutes (5–1440, configurable), and about 90 seconds after a local edit.
- The token is kept in the Harness credential store. It is never written to data files or returned to the agent, and the plugin refuses public repositories. Data is not end-to-end encrypted.

## Development

```
shared/host/common.js     Store, authenticated routes, tool registration, fetch helpers
shared/host/merge.js      three-way merge and the cross-plugin file lock
shared/client/kit.js      React helpers, icons and lp-* styles used by every panel
shared/client/glass.js    frosted-glass tokens (translucent layers, backdrop blur, ambient backdrop)
plugins/<name>/index.js   Host half: data, route /plugin-api/<name>, agent tool
plugins/<name>/src/client.js   Web half; `/* @kit */` is replaced by shared/client/kit.js
scripts/build.mjs         copies shared code into each plugin and assembles client.js
test/                     node --test suites (merge, GitHub sync against a local fake, Store)
```

Generated files are git-ignored. `npm test` builds and runs the tests; `npm run check` fails if a generated file is out of date.

Client code runs inside the Harness module loader and only uses `react` plus the `slots` and `locale` services. It does not import Harness client packages, so it keeps working across Harness UI updates.
